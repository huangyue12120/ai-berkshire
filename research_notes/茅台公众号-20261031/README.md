# 茅台2026Q3公众号稿：编辑与核验记录

制作日期：2026-10-31，北京时间。交付文件：`reports/茅台/茅台-公众号-20261031.md`。

本稿按 `wechat-article` 技能另行写作，面向普通长期投资者，正文约3150个汉字。依据是已完成并推送的《贵州茅台2026年三季报研究报告》（基准提交 `f86399188ca4e3a488e24d0374c1d48478c12bd6`），原研究报告保持不变。本次交付为公众号文稿及GitHub推送，不代表已在微信公众平台发布。

## 作者、编辑和读者流程

- 作者独立完成初稿，主线为利润来源、渠道迁移、金融本金现金流及投资判断。
- 编辑和读者并行审阅同一初稿，两者都指出“稳住了”“利润转正”容易误导，现金流科目过密，费用观察方向表述不准。
- 定稿取消提前宣布复苏或渠道改革成功的措辞，改为“利润恢复增长”；明确系列酒占的是收入增量，而非收入总额或利润增量。
- 简化财务公司现金流解释，将详细科目放在文末口径说明；保留销售收现与合并经营现金流的区分。
- 补充普通读者能持续核对的指标，并按主品牌收入、毛利与费用、回款与分红排序。
- 所有来源链接集中在最后的参考资料部分，正文没有来源链接。

初稿与两份完整审读意见留在本地工作目录；推送内容仅含定稿及必要核验记录。

## 数值复核

`verify.py` 从已核研究的 `research_notes/茅台财报-20261031/inputs.json` 重新计算公众号正文的18项财务数值，现金流四类本金、成本和合同负债原数另取同一研究保留的原始报表。计算采用Decimal，使用 `tools/financial_rigor.py` 检查估值，并调用 `tools/report_audit.py` 判决。每项保留原始计算值、展示精度、来源和口径限制。

18项均在所展示的小数精度上匹配。对约数先按文章精度四舍五入再送入抽检工具，避免3.5%与3.541%的正常舍入被误判为超过1%的相对偏差。完整精度仍保存在JSON中，不将舍入结果伪装成原始披露精度。

另已按原研究核对7月提价、8月管理层解释、2024—2026年不低于75%的分红规划。股息率是盈利不变及未来维持75%派息的测算，不是已宣布的未来派息；0.9%是全年持平所需的四季度增长门槛，不是业绩预测。

自动 `extract --seed 42` 对连续叙述识别不足，仅抓到参考资料标题中的年份，不能当作财务抽检。因此保留原提取结果，并以人工枚举18项、程序复算的补充核验完成检查，没有把年份当财务指标宣布通过。

这些核验复用刚完成研究的一手披露及交叉核对台账，不是新增独立审计，也不意味着18项全部重新取得了两个独立来源。终端消费者、复购与渠道库存的数据缺口保留在文章中。
