# 看懂快手②：可灵值多少钱，先问谁付成本

按假设重组完成的未经审计备考资料，可灵2025年收入约11亿元人民币、净亏损约19亿元人民币。本轮融资前估值则为150亿美元。技术与融资的成功，什么时候能变成快手普通股东的回报？

上一篇讨论了快手的成熟主业。这一篇把可灵拆开：客户为什么续费，收入要支付哪些成本，外部融资又怎样改变普通股东得到的那一份。

## 一、先把几组数字放回各自的口径

可灵已经形成商业收入，这是判断它的起点。过去的亏损和今天的融资价格，却不能直接连成一条估值公式。

| 指标 | 数值 | 时间、币种与性质 |
|---|---:|---|
| 收入 | 约11亿元人民币 | 2025年；假设重组完成的未经审计备考资料 |
| 净亏损 | 约19亿元人民币 | 2025年；同一备考口径，并非2026年最新亏损 |
| 季度收入 | 超过6.5亿元人民币 | 2026年第一季度，公司披露 |
| 季度收入 | 超过8.5亿元人民币 | 2026年第二季度，公司披露 |
| 年化收入运行率 | 约5亿美元 | 2026年3月的经营速度年化，并非已实现全年收入 |
| 融资前估值 | 150亿美元 | 本轮交易定价，附带相应合同权利 |
| 认购上限 | 30亿美元 | 8月31日公告确认上限已用满 |

收入描述一段时间内交付服务的商业规模，充值和流水则首先反映客户付款，两者的确认时间可能不同。运行率把某个阶段的速度年化，也没有回答客户能否持续续费。

融资估值包含投资者对未来的判断，以及他们取得的权利。新业务可以先投入、后产生回报，所以历史亏损不足以否定可灵；但机构愿意出资，也没有替普通股东证明未来现金回报。

## 二、客户真正需要的是稳定交付

消费者可能因为好奇买一次会员，专业客户却需要在可控时间和预算内，反复完成一段能交付的视频。两者都贡献收入，续费的理由很不一样。

一条精彩演示可能经过多次生成、筛选和后期修改。对客户而言，有效交付成本应包含失败样本、等待、人工编辑、审核和协调。单次生成便宜，最终完成工作仍可能很贵。

模型质量提高，可以减少重试；人物一致性、镜头控制和批量处理，可以减少人工修改；素材管理与协作功能，则可能降低团队沟通成本。这些环节合在一起，才构成客户实际使用的工作流。

API是软件之间调用服务的接口。可灵接入客户已有工具后，有机会成为日常生产的一部分；但如果客户只需替换一个接口，就能换用另一个模型，接入本身未必带来牢固关系。

更有价值的可能性，是客户逐渐沉淀角色、素材、模板和审核规则，切换时需要重新验证。可灵由此有机会把模型优势转成工作流优势。这是商业推演，并非公司已披露的客户合同事实。

技术竞争也在持续。可灵改善效果的同时，对手可能用更低价格提供接近的结果。企业还可以同时调用多个模型，让渠道掌握客户关系，模型供应商则承受价格压力。

因此，需要观察专业客户的留存，以及净收入留存率。前者看客户是否留下；后者是同一批客户下一期收入相对上一期的比例，同时计入流失、消费缩减和增购，观察这批客户贡献的收入怎样变化。目前相关分组数据仍披露不足。

## 三、每100元收入，还要付哪些账

视频生成每次都需要计算资源。视频越长、分辨率越高、重试越多，资源消耗也会变化。模型推理降本以后，客户还可能要求更复杂的输出，吃掉一部分降本成果。

先用一个教学例子理解单位经济性——每获得一份收入，为交付它需要付出多少成本。下表均为假设，每行收入都是100元，不是可灵实际成本或毛利率。

| 教学情景 | 直接生成及交付成本 | 渠道与服务费用 | 剩余贡献 |
|---|---:|---:|---:|
| 定价与利用率较好 | 25元 | 15元 | 60元 |
| 价格竞争、正常使用 | 45元 | 15元 | 40元 |
| 重试较多、价格承压 | 65元 | 15元 | 20元 |

**剩余贡献尚未扣除训练研发，也未扣除后续资本投入，不能称为净利润或自由现金流。**这张表只解释成本机制。

三种状态都能留下正贡献，但覆盖固定训练和研发预算的难度不同。若靠折扣和免费额度扩大使用，收入增长还可能伴随现金回收压力。

算力利用率同样重要。设备提前购置，需求不足时，折旧不会自动停止；需求突然增加，临时取得计算资源也可能更贵。要判断回报，需要同时看交付成本、设备利用率和客户付费。

2026年第一、第二季度，快手集团购买物业、设备及无形资产分别约121亿元、59亿元人民币。这是集团口径，不能全部归给可灵，但说明股东必须重视投入规模。

设备购置先消耗现金，再通过折旧分期进入利润表。收入上升与现金减少可以同时发生，今年买完设备，明年利润也可能继续承受折旧。观察毛利之后，还要继续看到研发费用与现金流。

## 四、融资带来资金，也重新分配收益

外部融资有现实价值：可灵可以获得更明确的资金来源，通过独立股权激励吸引人才，也有机会减少对快手成熟主业资金的依赖。相应代价，是未来收益需要分给更多参与者。

8月31日公告中的股权表，有一个必须连同数字保留的前提：**认购上限和股份计划授权上限均全部用满。**

| 项目 | 公告所列安排 | 应如何理解 |
|---|---|---|
| 认购进度 | 30亿美元上限已用满 | 不能直接推出全部款项已到账、全部激励已归属 |
| 快手条件经济权益 | Lucky Labs 66.33%，北京快灵瑞2.00%，合计68.33% | 认购及激励上限均用满后的表值 |
| 对应条件投票权 | 52.23%加1.57%，合计53.80% | 与经济权益分开，不是同一个比例 |
| 盖坤条件权益 | 3.00%经济权益、23.62%投票权 | 同一条件表；技术团队激励与控制安排需分别看 |
| 合并报表 | 交易完成后可灵仍继续并表 | 收入、费用和现金已进入集团财务 |

68.33%不是一项可以去掉前提、直接当作当日全部实缴和已归属权益的数字。认购进展、激励归属与经济权益变化，需要继续按具体公告更新。

股权激励如果帮助留住关键人才，可能扩大未来整个业务的价值。但普通股东也要检查：新增价值能否超过让出的权益，内部资源如何结算，未来是否还需继续投入。融资完成不了这项经营检验。

## 五、私募投资人与普通股东拿到的权利不同

7月2日公告赋予投资者约定回购权。发生相关触发事件后，投资者可在12个月内要求北京可灵回购全部或部分权益。

**什么时候触发**

上市期限方面，未能在约定最迟上市日期与2031年10月30日的较早者前完成首次公开发行，可触发回购。最迟上市日期是协议定义的“最迟付款日期”起算第五周年；最迟付款日期原则上为签约后120日，也可经持有超过50%认购金额的投资者批准调整。

另一组触发事项，是未在最迟付款日期后九个月内完成海外运营公司全部股权或主要资产业务的收购、取得所需增值电信许可及完成所需AI模型或算法备案。该期限可由持有投资者表决权过半数者同意调整；法律不要求的许可及备案另有例外。

**已申请上市怎么办**

上市申请也有延期安排：若在最迟上市日期已正式提交申请，回购权暂不能行使，直至出现提交后12个月未上市、申请失效且未及时重交或遭拒、主动撤回等约定事件中的较早者。因此，2031年不是一个无条件回购日。

**回购价与责任主体**

回购价为相关权益的原始投资价，加从投资者悉数支付增资款日至回购价款支付日按年利率8%计算的单利回报，不足一年按比例计算；加已宣告未支付股息，再减回购通知前已收到的股息及分派。

付款义务主体是北京可灵，公告定义的北京可灵集团公司承担连带责任。该范围不能扩大为快手上市母公司提供无限担保。

快手普通股东没有同样的合同权利。新投资者在特定情况下有退出救济，普通股东则继续承担经营与资本分配后的剩余风险。因此，私募融资是有价值的价格参考，却不能直接当作上市普通股的价值底线。

融资前150亿美元，加认购上限30亿美元，对应投后180亿美元的算术框架。投后价值已经包含新钱；若先按投后价值计入可灵，再把融资款全部加进集团现金，会重复计算。

还有更隐蔽的一次重复：集团DCF，即现金流折现估值，若已经包含可灵未来收入、成本和投入，就不能再额外加一遍可灵投后价值。AI若改善广告业务现金，同一项协同也只能计算一次。

若做分部估值，就要先完整剥离可灵的收入、费用、资本开支和内部结算，再按适当经济权益加入。目前披露不足以精确完成这一步。本系列因此把融资作为参考，主估值仍回到集团未来归属于普通股东的现金。

## 六、接下来，哪些证据最有价值

可灵未来可能成为不同类型的生意。下表是情景分析，不是公司预测，也没有赋予主观概率。

| 可能走向 | 对股东意味着什么 | 优先观察的证据 |
|---|---|---|
| 专业工作流平台 | 有机会形成持续利润来源 | 专业客户留存、扩张收入、全成本盈利 |
| 高效模型供应商 | 有规模价值，但受渠道议价约束 | 有效交付成本、利用率、毛利与现金 |
| 主要帮助成熟主业 | 收益体现在广告和电商中 | 商家回报与集团现金同步改善 |
| 收入快增、资本回报低 | 新收入持续被竞争和投入消耗 | 收入增长同时，亏损与资本开支也增加 |
| 商业化或退出受阻 | 资产承压，并可能触发合同义务 | 客户流失、现金消耗、回购条件变化 |

这些状态可能互相转化。产品可以先成为高效供应商，再沉淀客户工作流；也可能先靠领先效果赢得收入，后来被低价竞争削弱。

下一份更有价值的披露，应当告诉我们：哪类客户持续付费，完成一份可用视频耗费多少资源，训练和资本投入之后留下多少现金，以及这些现金最终归谁。

可灵已经证明有人愿意为它付钱。下一步要证明的是：客户持续使用的同时，快手普通股东也能持续获得回报。第三篇将把成熟主业、AI投入与集团财务放到同一张估值表里。

*资料截至2026年9月6日。本文用于学习与研究，不构成投资建议；成本示例与未来情景均为分析假设。*
